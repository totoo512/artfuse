# Creation 页面开发指南

## 项目概述

Creation 页面是一个基于 UniApp 开发的 AIGC 风格化图片生成应用的核心功能页面。该页面允许用户上传人物照片和看展照片，通过 AI 技术生成风格化图片，并提供保存、分享等功能。

## 功能架构

### 核心功能模块

1. **素材上传模块**
   - 人物照片上传（单张）
   - 看展照片上传（最多9张）
   - 从个人相册选择

2. **AI 生成模块**
   - 风格化图片生成
   - 多阶段生成进度提示
   - 生成结果展示

3. **扩展功能模块**
   - 视频生成选项
   - 智能文案生成
   - 图片保存和社交分享

### 2. 素材上传功能

#### 2.1 人物照片上传

**功能特点**:
- 仅支持单张照片上传
- 作为风格化处理的主体人物
- 支持相机拍摄和相册选择
- 自动压缩图片优化性能

**技术实现**:
```javascript
const uploadPortrait = () => {
  uni.chooseImage({
    count: 1,
    sizeType: ['compressed'],
    sourceType: ['camera', 'album'],
    success: (res) => {
      portraitImage.value = res.tempFilePaths[0]
    }
  })
}
```

**优化建议**:
- 添加图片裁剪功能
- 支持人脸检测和定位
- 添加图片质量检查
- 支持多种图片格式

#### 2.2 看展照片上传

**功能特点**:
- 支持最多9张照片上传
- 提供艺术风格参考
- 支持批量选择和单独删除
- 网格布局展示

**交互功能**:
- 点击图片预览
- 点击删除按钮移除
- 添加按钮继续上传
- 显示当前数量限制

**优化建议**:
- 添加拖拽排序功能
- 支持图片压缩选项
- 添加批量删除功能
- 支持从云端相册选择

### 3. AI 图片生成功能

#### 3.1 生成条件检查

**必要条件**:
- 必须上传人物照片
- 必须至少上传一张看展照片

**计算属性实现**:
```javascript
const canGenerate = computed(() => {
  return portraitImage.value && exhibitionImages.value.length > 0
})
```

#### 3.2 生成流程

**处理阶段**:
1. 人物特征分析
2. 艺术风格应用
3. 图片质量优化
4. 结果展示

**状态管理**:
- `isGenerating`: 生成状态控制
- `loadingText`: 动态加载提示
- `generatedImages`: 生成结果存储

**扩展建议**:
- 接入真实 AI 生成 API
- 支持多种艺术风格选择
- 添加生成质量等级
- 支持批量生成和高分辨率输出

### 4. 生成结果管理

**交互逻辑**:
- 支持单选模式
- 点击切换选中状态
- 选中状态视觉反馈

**实现方式**:

const selectImage = (index) => {
